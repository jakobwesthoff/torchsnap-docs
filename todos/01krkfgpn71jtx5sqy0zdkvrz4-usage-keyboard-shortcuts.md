# Keyboard Shortcuts

Path: `usage/keyboard-shortcuts/`

- Global launcher shortcut: `CmdOrCtrl+Shift+Space` (default)
- How to customize the global shortcut
- Per-gadget shortcuts (e.g., clipboard manager `CmdOrCtrl+Shift+V`)
- In-launcher keybindings: navigate results, execute, dismiss, actions
- Platform differences:
  - macOS: global shortcuts managed by the app
  - Linux: may need to be configured via Wayland compositor / window manager instead
- Modifier key mapping: `Meta` = Cmd on macOS, Ctrl on Linux
