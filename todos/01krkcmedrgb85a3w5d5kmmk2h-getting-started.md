# Getting Started

Comprehensive user-facing getting started guide. Path: `usage/getting-started/`

Sections:
- **Installation** — download, platform requirements (macOS today, Linux next)
- **Basic usage** — global shortcut (`CmdOrCtrl+Shift+Space`), search, execute, dismiss
- **Configuration** — settings UI overview, `settings.json` location
- **Keybindings** — global shortcut customization, per-gadget shortcuts, modifier keys, layers
- **Built-in gadgets overview** — brief list with one-liner per gadget (link to individual pages):
  - Native: App Launcher, System Preferences, Clipboard Manager, System Commands, Builtin Commands
  - Bundled WASM: Calculator, Emoji Picker, Bangs, Open URL, ZeroTier
