# Hooks & Runtime API

Path: `development/gadget-sdk/frontend/hooks/`

- `useGadgetInfo()` — gadget metadata
- `useGadgetRuntime()` — runtime context
- `useLauncher()` — launcher interaction (dismiss, query, etc.)
- `useGadgetSetting<T>(key)` — typed setting read/write
- `useWindowedList(params)` — virtualized list rendering
- `@torchsnap/gadget-sdk/components` — host-provided UI components
- `@torchsnap/gadget-sdk/keybindings` — keybinding utilities
- `@torchsnap/gadget-sdk/utils` — utility functions
