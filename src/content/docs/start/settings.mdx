Open Settings by right-clicking the Torchsnap tray icon in the menu bar and
choosing **Settings...**, or by searching for "Settings" in the launcher.

## General

<Screenshot dark={settingsGeneralDark} light={settingsGeneralLight} alt="Settings window showing the General section" maxWidth="600px" />

| Setting | Description |
|---|---|
| **Launch at login** | Start Torchsnap automatically when you log in. |
| **Global Shortcut** | The system-wide shortcut that opens the launcher. Click **Change** to record a new one. Default: <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> on macOS, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> on other platforms. On Linux under Wayland, global shortcuts may need to be registered through the desktop environment instead. See [Keyboard Shortcuts](/start/keyboard-shortcuts/) for details. |
| **Control API** | Enable the JSON-RPC control socket so external programs can drive Torchsnap. Disabled by default. See [Control API](/control-api/) for details. |

### Snappy the mascot

Snappy is the owl mascot that sits on top of the launcher. You can customize
how Snappy appears, or hide it entirely.

<Screenshot dark={mascotCosplayDark} light={mascotCosplayLight} alt="Launcher with Snappy in default centered mode wearing a costume" />

| Setting | Description |
|---|---|
| **Show Snappy mascot** | Toggle Snappy on or off. |
| **Snappy is only a Sidekick** | In the default mode, Snappy is centered above the search bar at full size. Enabling sidekick mode shrinks Snappy to half size and moves it to the right edge, keeping the launcher more compact. |
| **Let Snappy do Cosplay** | Snappy picks a random costume from over 150 hand-drawn variants each time the launcher opens. Costumes range from sci-fi and fantasy to pop culture references and seasonal outfits. Disable this to always show the original Snappy. |
| **Enable non family-friendly mascots** | Some Snappy variants carry props like swords, daggers, or lightsabers. Disable this to filter those variants from the random rotation. Only available when cosplay mode is enabled. |

In sidekick mode, Snappy moves to the right edge of the search bar at half
size, still present but out of the way:

## Frecency

<Screenshot dark={settingsFrecencyDark} light={settingsFrecencyLight} alt="Settings window showing the Frecency section" maxWidth="600px" />

Frecency combines **frequency** (how often you use something) and **recency**
(how recently you used it) into a single score. The more you launch a
particular result, the higher it ranks, but recent usage counts for more than
old usage, so the ranking naturally adapts as your habits change.

This means Torchsnap learns your preferences over time without any manual
configuration. The apps and commands you rely on daily float to the top, while
things you stopped using gradually fade back down.

Frecency data is stored locally and records which result was launched and when.
If you prefer not to have that usage history stored on disk, you can disable
frecency tracking entirely or clear the history at any time.

| Setting | Description |
|---|---|
| **Enable frecency tracking** | Toggle frecency ranking on or off. |
| **Statistics** | Shows how many events have been recorded, broken down by gadget. |
| **Clear history** | Permanently delete all frecency data and start fresh. |

## Gadgets

<Screenshot dark={settingsGadgetsDark} light={settingsGadgetsLight} alt="Settings window showing the Gadgets section" maxWidth="600px" />

The Gadgets section lets you manage which gadgets are active. Each gadget
shows its version after its name and a permission line below it. The line
names what the gadget touches: programs, network, files, links, the
clipboard or its own data. Click it to see every permission. Groups that
reach beyond the gadget's own data carry a **Broad access** label; hover it
for an explanation. Built-in gadgets are native code and have no permission
list.

| Action | Description |
|---|---|
| **Enable / disable** | Toggle individual gadgets on or off using the switch next to each one. |
| **Install** | Drop `.torchsnap` files onto the drop zone, click **Choose a file...**, or double-click a `.torchsnap` file in Finder. Every install shows a review first. Installed gadgets take effect after a restart. |
| **Replace** | Installing another version of an installed gadget replaces it and keeps its data and settings. |
| **Uninstall** | Remove user-installed gadgets. The gadget shows **Removed on restart** until the next start, when its data and settings are deleted. Built-in and bundled gadgets ship with the app and cannot be removed. |
| **Undo** | Take back an install, update or uninstall before the restart. |

### Changes waiting for a restart

Installs, updates and uninstalls take effect when Torchsnap restarts. Until
then the gadget's row says what happens, for example **Installs on
restart**, **Updates to 1.2.0 on restart** or **Removed on restart**, and
has an **Undo** button. Rows are dimmed, except for updates, where the
installed version keeps running until the restart. A bar at the top counts the waiting
changes and offers **Restart now**. After that restart, Torchsnap opens this
section again.

### Install review

Before a gadget is installed, Torchsnap opens this section and shows:

- the gadget's name, version, id and description, and the file it comes from;
- the site the file was downloaded from, when macOS recorded it for the download;
- every permission the gadget asks for.

When the file replaces an installed version, the review also names both
versions, warns when the new one is older, marks permissions the installed
version did not have as **New**, and lists the ones it no longer asks for.

Several files are reviewed one after another. The review groups permissions
the same way as the permission line.

Individual gadgets may have their own settings. These appear in the sidebar
under the gadget's name when available.

## Settings file

All settings are stored in a JSON file at the platform's application data
directory:

| Platform | Path |
|---|---|
| macOS | `~/Library/Application Support/app.torchsnap/settings.json` |
| Linux | `~/.local/share/app.torchsnap/settings.json` |
| Windows | `%APPDATA%\app.torchsnap\settings.json` |

You generally don't need to edit this file directly since the Settings UI covers
everything. But it can be useful for backup, scripting, or troubleshooting.
