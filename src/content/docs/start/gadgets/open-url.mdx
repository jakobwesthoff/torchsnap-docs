Open URL detects web addresses typed into the search bar and lets you open them
directly in your default browser.

<Screenshot dark={openUrlDark} light={openUrlLight} alt="Typing 'westhoffswelt.de' showing the detected URL with page title and favicon" />

## How it works

The gadget activates automatically when it recognizes a URL in the search bar.
Two formats are supported:

- **Full URL** — type `https://example.com` or `http://example.com`. Always
  produces a result, even if the site is unreachable.
- **Bare domain** — type a domain like `github.com` or `example.co.uk`. The
  gadget validates the domain against the Public Suffix List and only shows a
  result if the TLD is recognized and the site is reachable.

When a URL is detected, Torchsnap fetches the page title and favicon to display
alongside the result.

## Actions

| Action | Shortcut | Description |
|---|---|---|
| **Open in Browser** | <kbd>Enter</kbd> | Open the URL in the default browser. |
| **Copy URL** | <kbd>Cmd</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the full URL to the clipboard. |
