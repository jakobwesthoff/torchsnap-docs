The App Launcher lets you find and open any installed application by typing
part of its name.

<Screenshot dark={appLauncherDark} light={appLauncherLight} alt="Searching for 'appl' showing applications and system settings" />

## How it works

All installed applications are indexed at startup and kept up to date with a
background refresh every five minutes. Results appear instantly — there is no
manual setup required.

Each result shows the application name, its file path, and the app's own icon.

### Technical details

<Aside type="note">
  This section is for the technically curious. You don't need any of this
  to use the App Launcher — it just works out of the box.
</Aside>

<Tabs>
  <TabItem label="macOS">
    Applications are discovered via Spotlight (`mdfind`) using the query
    `kMDItemContentType == 'com.apple.application-bundle'`. Only bundles under
    an `/Applications/` directory are included — this covers `/Applications/`,
    `/System/Applications/`, and `~/Applications/`. Framework helpers and
    bundles in other locations are filtered out.

    The display name is resolved from the app's `Info.plist` in priority order:
    `CFBundleDisplayName`, then `CFBundleName`, then the `.app` filename as a
    fallback.

    Icons are extracted via `NSWorkspace.iconForFile()`, which returns the
    system-composited icon including any dynamic overlays.
  </TabItem>
  <TabItem label="Linux">
    <Aside type="caution" title="Under construction">
      Linux app discovery is planned but not yet implemented. It will scan
      `.desktop` files from XDG data directories.
    </Aside>
  </TabItem>
  <TabItem label="Windows">
    <Aside type="caution" title="Under construction">
      Windows app discovery is planned but not yet implemented. It will
      enumerate Start Menu shortcuts.
    </Aside>
  </TabItem>
</Tabs>

## Actions

| Action | Shortcut | Description |
|---|---|---|
| **Open** | <kbd>Enter</kbd> | Launch the application. |
| **Reveal in file manager** | <kbd>Cmd</kbd>+<kbd>Enter</kbd> / <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Show the application in the file manager without launching it. |
