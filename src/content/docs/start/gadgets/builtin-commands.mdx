Builtin Commands provides always-available Torchsnap-specific actions.

<Screenshot dark={builtinDark} light={builtinLight} alt="Searching for 'quit' showing the Quit Torchsnap command" />

## Available commands

| Command | Description |
|---|---|
| **Settings** | Open the Torchsnap [Settings](/start/settings/) window. Also searchable as "preferences", "config", or "options". |
| **Quit Torchsnap** | Exit the application. Also searchable as "exit" or "close". |
| **Developer Tools** | Open the built-in developer tools for debugging. |

## Actions

| Action | Shortcut | Description |
|---|---|---|
| **Execute** | <kbd>Enter</kbd> | Run the selected command. |
