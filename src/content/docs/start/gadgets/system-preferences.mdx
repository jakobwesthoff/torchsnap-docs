System Preferences lets you jump directly to a specific settings pane by
searching for its name.

<Screenshot dark={systemPrefsDark} light={systemPrefsLight} alt="Searching for 'sound' showing the Sound settings pane" />

## How it works

All available settings panes are indexed at startup. You can also search using
the keywords "settings" or "preferences" to browse the full list.

Each result shows the pane name, "System Settings" as the subtitle, and the
pane's icon.

## Actions

| Action | Shortcut | Description |
|---|---|---|
| **Open** | <kbd>Enter</kbd> | Open the settings pane directly. |
