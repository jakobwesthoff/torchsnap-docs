Torchsnap is a keyboard-driven application launcher. Press the default global
shortcut — <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> on macOS or
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> on other platforms — to open
the search bar, type to find what you need, and press <kbd>Enter</kbd> to
launch. Press <kbd>Escape</kbd> to dismiss — first press clears the query,
second press closes the launcher. The shortcut can be changed in
[Settings](/start/configuration/).

Results update on every keystroke with fuzzy matching. Arrow keys navigate the
list, and a footer bar shows secondary actions available for the selected
result.

Out of the box, Torchsnap ships with gadgets that search applications, manage
clipboard history, run system commands, evaluate math expressions, pick emoji,
and more. Everything is extensible through the gadget system — sandboxed
WebAssembly plugins you can build yourself.
