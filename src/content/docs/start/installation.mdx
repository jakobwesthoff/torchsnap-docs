## macOS

Torchsnap runs on Macs with Apple silicon. Macs with an Intel processor are
not supported.

### DMG Download

Download
[Torchsnap.dmg](https://github.com/jakobwesthoff/torchsnap/releases/latest/download/Torchsnap.dmg)
from the latest release, open it, and drag Torchsnap into your Applications
folder.

<Screenshot dark={dmgDark} light={dmgLight} alt="Torchsnap DMG installer window" maxWidth="400px" />

### First launch

When you open Torchsnap for the first time, macOS asks whether you want to
open an app downloaded from the internet. Click **Open**. The dialog also
says that Apple checked Torchsnap for malicious software: every release is
notarized by Apple before it is published.

### Homebrew

A Homebrew tap is not yet available. Use the DMG download for now. Once
published, the install command will be:

```sh
brew install jakobwesthoff/tap/torchsnap
```

## Linux

Linux support is planned. Platform-specific packages (`.AppImage`, `.deb`)
will be provided once available.

## Windows

Windows support is planned.
