  - SDK helpers: parse\_payload, to\_response
  - impl\_noop\_messaging! for gadgets without RPC
- tasks: run-task(task-id)
  - Cron scheduling via manifest [[tasks]] entries
  - Best-effort: errors logged, gadget not disabled
  - impl\_noop\_tasks! for gadgets without scheduled work
