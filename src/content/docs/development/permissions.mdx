TODO: Permission model reference.

- Deny-by-default: capabilities not declared in manifest are unreachable
- Boolean permissions: clipboard, frecency, website-metadata
- Always-available interfaces: logging, settings, assets, platform, path-resolver
- Opener permissions: schemes allowlist, open-path, reveal-path
- HTTP permissions: origins allowlist, wildcard trust-all
- Filesystem permissions: read globs, substitution variables, symlink resolution
- Command permissions: per-binary argv-shape rules, constraint kinds
- SQL storage: declared via [storage.sql], not a permission flag
- Substitution variables: gadget-data, gadget-archive, home, xdg-config, xdg-data
